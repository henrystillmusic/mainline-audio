Per-Band Targeting
Assign any band independently to Stereo, Mid, Side, Left, or Right. Different routing modes can be combined freely across all six bands, letting one band shape the center while another works on width or an individual channel.
Every Phase Engine
The same per-band routing remains available in Minimum, Natural, and Linear phase, so changing phase behavior never changes where your EQ is targeted.
Phase

Three engines. One curve.

Each phase engine processes the same six-band curve through a genuinely different signal path. Switch engines to match the mastering situation, not just the sound.

Minimum
The default engine. Zero added latency, classic minimum-phase EQ response.
Natural
A continuous, always-live engine that trades Minimum's zero-latency immediacy for linear-phase processing with lower latency than Linear.
Linear
Full linear-phase precision — greater frequency resolution with a fixed amount of added latency.
Monitoring

Four ways to work the curve

Every comparison tool is built to answer one question honestly: what is this specific move actually doing.

Bypass
Instant, click-free bypass — registered as the plugin's own host-visible bypass parameter for reliable A/B against your DAW's own compare tools.
Audition
Solo any band's contribution directly on the curve and in the signal — every other band recedes so you can hear and see exactly what one move is doing.
Isolate
Press and hold to preview a band in isolation — a fast way to confirm you're reaching for the right frequency before you commit.
A / B
Two full parameter snapshots, one click apart. Flip between them instantly while you decide.
Metering

See the curve, not just hear it

A light, honest read of what's happening — not a second metering suite bolted onto an EQ.

Spectrum Analyzer
Off, Pre, Post, or Pre + Post, with an opacity control that keeps the curve the hero, not the noise floor underneath it.
Output Level
A basic peak/level meter paired with Output Trim, plus Auto Gain's own compensation readout, so you always know exactly what's leaving the plugin.

FAQ

What is The Fine Line?

A precise, restrained mastering equalizer built for exact numeric control with minimal visual noise — six bands, three phase engines, Tilt, and Contour, with independent Stereo, Mid, Side, Left, or Right routing available on every band.

Can I get it now?

Yes — The Fine Line is available now.

What formats are supported?

VST3 and AU on macOS (Apple Silicon & Intel, Universal). AAX / Windows are not currently supported.

How many computers can I install it on?

Up to 2 computers that you own or control. Deactivate a machine at any time to free up an activation.
