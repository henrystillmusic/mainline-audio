Contour

Three ways to let go.

Release is the control most compressors leave to a single number. Contour adds a second, slower envelope that tracks recent program activity and stretches recovery in proportion to it — so an isolated peak releases at close to the nominal rate, while a peak landing on top of sustained loudness recovers more slowly. The same Release setting will not feel identical across the three modes.

Transparent
Your Release setting, unmodified. The neutral core — no added program dependence.
Cohesive
Moderate program dependence. Successive events influence one another, and the mix moves more as one system.
Deep
The same mechanism reaching further: memory persists longer and engages with less headroom, for denser, longer-term movement.

Contour reshapes release only. It adds no saturation, harmonic coloring or analog modelling.

What is The Main Squeeze?

A feed-forward mastering compressor with a stereo-linked peak detector, a 6 dB soft knee, a detector-only sidechain high-pass, and three Contour modes that reshape release.

What does Contour actually change?

Release, and only release. Transparent uses your Release setting unmodified. Cohesive and Deep add a slower memory envelope that extends recovery based on recent program activity. Attack, the compression curve, and the soft knee remain identical in all three modes, with no added saturation or harmonic coloring.

Does the sidechain high-pass filter my audio?

No. It filters only what the compressor's detector listens to. The audio you hear is never high-passed.

What formats are supported?

VST3 and AU on macOS (Apple Silicon & Intel, Universal). AAX / Windows are not currently supported.

How many computers can I install it on?

Up to 2 computers that you own or control.
