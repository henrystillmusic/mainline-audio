The Last Look 1.0.0

Released 13 October 2026 · Initial release

The first release of The Last Look — complete metering and analysis for final mix/master decisions.

  • Formats. AU, VST3, and Standalone for macOS (Apple Silicon & Intel, Universal).
  • Demo. A 14-day, full-featured demo is available.
  • Reference files. Load a reference file — including MP3 — for direct comparison against your own mix.
  • Delivery checks. True peak, clipping, inter-sample overs, and DC offset, flagged before you export.
  • Reference & audition workflow. Switch between your mix and a loaded reference to judge level and tonal balance side by side.

This is the initial release — there is no prior version to compare against.

Henry Still

Mastering Engineer · Founder, Mainline Audio
